# Nabd

Blood donation app. Mobile Application Development coursework, Phase 1.

## How to run

```
npm install
npx expo start
```

Scan the QR code with Expo Go (SDK 57).

## Folder structure (MVVM)

- `models/` - data types and sample data (Model)
- `viewmodels/` - state and logic for the screens (ViewModel)
- `app/` and `components/` - the screens (View)
- `constants/` - colours

## Screens

| Member | Screens |
|---|---|
| 1 - Requests | Requests List, New Request, Request Details |
| 2 - Map | Hospitals Map, Find Donors, Hospital Details |
| 3 - Donation | Can I Donate?, Book Appointment, My Donations |
| 4 - Profile | Profile, Notifications, Settings |
